# **SENTINELA**
### **Plataforma Inteligente de Monitoramento e Detecção de Anomalias**

Projeto acadêmico desenvolvido na FIAP para o **Sentinela Nuclear Challenge**, com foco na centralização de dados, detecção de anomalias e correlação de eventos em ambientes críticos.

## **Sobre o Projeto**

O Sentinela propõe uma plataforma web inteligente capaz de reunir informações provenientes de diferentes fontes de monitoramento, identificar eventos fora dos padrões estabelecidos e correlacionar ocorrências relacionadas.

A solução busca transformar dados dispersos em alertas contextualizados, oferecendo suporte à análise e à tomada de decisão dos operadores humanos.

O protótipo acadêmico utilizará dados simulados e arquivos demonstrativos, sem depender de equipamentos ou instalações reais.

## **Objetivos**

- Centralizar informações de diferentes fontes de monitoramento.
- Simular eventos provenientes de sensores e dispositivos.
- Identificar possíveis anomalias por meio de regras e visão computacional.
- Correlacionar eventos considerando horário, localização e tipo de ocorrência.
- Gerar alertas contextualizados.
- Registrar ocorrências e decisões dos operadores.

## **Funcionalidades Previstas**

- Dashboard de monitoramento.
- Mapa com localização simulada dos dispositivos.
- Central de alertas e análise de ocorrências.
- Histórico e auditoria de decisões.
- Simulação de sensores e dispositivos.
- Análise demonstrativa de imagens e vídeos.

## **Tecnologias e Ferramentas**

Tecnologias candidatas para o desenvolvimento:

- **Frontend:** React
- **Backend:** Python e FastAPI
- **Visão computacional:** OpenCV e YOLO
- **Banco de dados:** PostgreSQL
- **Mapas:** Leaflet
- **Versionamento:** Git e GitHub
- **Prototipação:** Figma

*As tecnologias listadas representam possibilidades técnicas e poderão ser ajustadas durante o desenvolvimento.*
